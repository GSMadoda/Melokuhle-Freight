# Melokuhle Freight

Website for Melokuhle Freight (Pty) Ltd — road, sea and cross-border freight between South Africa and the DRC.

Static single page: `index.html` + `assets/logo.jpg`. Open `index.html` in a browser, or host it free with GitHub Pages (Settings → Pages → Deploy from branch `main`, folder `/`).

Before going live, replace the placeholder WhatsApp/phone number `27000000000` / `+27 00 000 0000` in `index.html` with the real one.
